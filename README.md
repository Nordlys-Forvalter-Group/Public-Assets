# Public assets

Display files for Nordlys Forvalter Group. These are the logo files from the brand kit, version 1.0.

Use the file that stays clear on its background. Do not stretch, recolour, rotate, or redraw the mark. Leave a margin around it at least as wide as half the emblem.

| File | Use |
| --- | --- |
| [logos/logo-horizontal.png](logos/logo-horizontal.png) | Default lockup on a light ground. 2480×800. |
| [logos/logo-horizontal-reversed.png](logos/logo-horizontal-reversed.png) | White wordmark for Nordlys Navy `#003057` or another dark ground. 2480×800. |
| [logos/logo-stacked.png](logos/logo-stacked.png) | Narrow or square, light ground. 1440×1520. |
| [logos/emblem-color.png](logos/emblem-color.png) | Colour emblem for an icon on a light ground. 1600×1600. |
| [logos/emblem-reversed.png](logos/emblem-reversed.png) | Colour emblem for a dark ground. 1600×1600. |
| [logos/emblem-mono.png](logos/emblem-mono.png) | One-colour emblem, white ribbon on a navy disk. 1600×1600. |

Empty pixels are transparent.

| Name | Hex |
| --- | --- |
| Nordlys Navy | `#003057` |
| Paper | `#F7F9FA` |
| Ink | `#0E1B24` |

Headlines are Poppins. Body text is Inter. The smallest horizontal lockup is 120 pixels wide. The smallest emblem is 24 pixels wide.
